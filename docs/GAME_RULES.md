# あいうえおゲーム ゲームルール

> 2026-09-29確認。以下のゲームルールはユーザー指定の内容を反映しています。現行コードで未実装の項目は、末尾の「実装状況」を参照してください。

## ゲームの概要

お題に沿った言葉を各プレイヤーが秘密に登録し、50音表から選ばれた音を順に公開していく複数人ゲームです。自分の言葉がすべて公開されたプレイヤーは脱落し、最後まで生き残ることを目指します。

## ルール

1. お題を決め、各プレイヤーがそのお題に沿った言葉を1つ入力します。
2. 入力した言葉は他のプレイヤーに見えないよう伏せ字で表示します。
3. 最初の手番は参加プレイヤーからランダムに決めます。以後はプレイヤーID昇順で循環し、脱落済みのプレイヤーは飛ばします。
4. 手番プレイヤーは未開放の音を1つ選びます。1回の手番で開放するのは1音です。
5. 選ばれた音と一致する伏せ字を、全プレイヤーのワード上で同時に文字表記へ切り替えます。同じ音が1つのワードに複数回ある場合も、該当箇所を全て同時に開放します。選んだ音は使用済みになります。
6. 該当する文字があるかどうかにかかわらず、選んだ音は使用済みになります。
7. 言葉の全ての文字が公開されたプレイヤーは脱落し、以後の手番から外れます。
8. 次の生存者へ手番を渡し、音の選択・公開・脱落の判定を繰り返します。

## 終了条件と順位

次のどちらかでゲームを終了します。

- 最後の1人になるまで生き残った。
- 生存者全員の未公開文字が、同じ1種類の音だけになった。

最後まで生き残ったプレイヤーが1位です。特殊終了条件を満たして終了した場合は、その時点の生存者全員を同率1位とします。1回の音開放で全員が同時に脱落する場合も、同じ状態で脱落した全員を同率1位とします。

## 現行コードで確認できる初期設定

- プレイヤー人数は2〜8人、初期値は2人です。
- お題候補は「たてもの」「たべもの」「くるま」「さかな」「はな」の5種類です。`odai.csv` の内容はまだ読み込まれていません。
- 50音表は5行×10列で、空欄セルと「ん」を含みます。「ー」は50音とは別の1音として追加します。
- 濁音・半濁音は対応する清音へ、小さい「っ」「ゃ」「ゅ」「ょ」は大きい文字へ強制変換し、同じ音として扱います。
- ワードは1〜7文字です。8文字以上の入力はエラーとして通知し、登録しません。

## 実装状況

現行 `index.html` と `script.js` は、人数選択、プレイヤー名編集、ワード入力欄の伏せ字表示、50音表の音選択・使用済み表示までを実装しています。一方、今回確認したルールのうち、以下はまだ実装されていません。

手番は生存者間で順番に回すルールですが、現行コードには手番管理がありません。

- 選んだ音と各プレイヤーの言葉を照合し、該当する伏せ字を公開する。
- 全ての文字が公開されたプレイヤーを脱落させる。
- 生存者の未公開文字を調べ、終了条件を判定する。
- 1位・同率順位を決めて表示する。
- 「New Game」ボタンで状態を初期化する。
- 「お題編集」ボタンでお題を変更する。

## 現行コードとの差分

- 現行コードは濁音・半濁音と小書き文字の一部を変換しますが、全ての対象文字を網羅しているわけではありません。
- 現行の `sanitizeWord` は8文字まで残し、超過時にエラー通知しません。確定済みワードの伏せ字も固定8個です。いずれも7文字制限のルールに合わせて修正が必要です。
- 現行コードにはランダムな初手、プレイヤーID昇順の循環、脱落者のスキップ、該当なし時の手番進行がありません。
